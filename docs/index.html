Ratchet

Working rules for AI coding agents. Each rule names the check that fails when the rule is broken.

A rule that no check can see is marked text only, with the reason. So nothing claims a protection it does not have.

Start here GitHub README

Why it exists

AI agents read your instructions and still say “done” without running the tests. The maintainer had more than 100 repos built by agents, and no longer knew what governed the agents in them. Now each repo owns its rules, in one file, and borrows them from Ratchet.

How it works

  1. Your repo keeps a register. One file, register.json, lists every rule in force: the ones you borrow from Ratchet, and your own. Ratchet's own register
  2. Each rule names its ratchet. That is the check that fails when the rule is broken, or the words “text only”. Your register says which checks you have built. The rules
  3. A failure becomes a check. The check gets a fixture it must fail on, so the same failure cannot quietly come back. The loop

Ratchet today: the core has 19 rules. 13 name a check and 6 are text only.

The principles

Each is a question to ask when no rule fits. The rules stand under them. Read them in full

  1. Keep one place
  2. Make the gate independent of the author
  3. Wait for the owner on what cannot be undone
  4. Show the run, and treat silence as red
  5. Make checks that can fail, and turn failures into checks
  6. Guard the boundaries
  7. Subtract first

Start here

Run these in the root of your own git repo.

  1. Fetch Ratchet at the latest release. 
    git clone --branch v0.11 https://github.com/fabian-von-tiedemann/ratchet .ratchet
  2. See what it would write. This writes nothing. 
    python3 .ratchet/checks/init.py --check
  3. Write it. 
    python3 .ratchet/checks/init.py
  • In a new repo, it writes AGENTS.md, register.json with the rules to start with, the generated REGISTER.md, and a workflow that checks the register on every pull request.
  • In a repo with an instruction file of its own, such as AGENTS.md or CLAUDE.md, it writes only register.json and never changes your file.

It never overwrites a file. What to do next

Ratchet is open source. Take the rules that fit your project, leave the rest, and send back what you learn. It restates ideas from public sources in its own words, and credits them rule by rule.
